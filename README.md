# MusicBrain · What my music sounds like

Interactive results of a personal machine-learning project: my whole Spotify library (3,751 songs, 1,862 artists)
analysed by how it sounds, how it feels and where it comes from.

**Live page:** https://leolfsh.github.io/MusicBrain/

## What's inside

| Section | What it shows | Method |
|---|---|---|
| Taste galaxy | Every song placed by how it sounds; find a song and see the 5 songs that sound most like it | Essentia Discogs-EffNet embeddings (1,280-d) → UMAP; cosine nearest neighbours |
| Emotion map | Valence (sad → happy) vs. arousal (calm → intense) | Essentia emoMusic (MusiCNN) |
| Mood | Whole library vs. recent favourites | Essentia mood classifiers |
| Key wheel | Musical keys on the circle of fifths | Essentia KeyExtractor |
| Tempo | BPM distribution per genre | Essentia RhythmExtractor2013 |
| Instruments | 40 instruments detected | MTG-Jamendo instrument model |
| Time | Release years and when songs were saved | Spotify Web API |

Audio comes from 30-second previews. Metadata from Spotify, Last.fm, Discogs and MusicBrainz.

## Files

- `index.html`: the page (Plotly.js charts, no build step)
- `data/library.json`: one row per analysed song, plus summaries
- `img/`: spectrogram cover and song card

The data is generated by `build_site.py` in the main project. To update the page, re-run it and upload the new
`data/library.json`.

## Roadmap

K-Means taste clusters (silhouette / elbow validation) → a recommender with a small neural taste model and
novelty-aware ranking → producer/engineer credits → world map of artist origins → listening history over time.
